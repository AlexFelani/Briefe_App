# Briefe-App

Behördenpost verstehen, ordnen und beantworten – in der eigenen Sprache.

| Ordner | Inhalt |
|---|---|
| `briefe-web/` | Die App (React). Briefe, Fotos und Fälle bleiben auf dem Gerät. |
| `briefe-server/` | Der Server: KI-Zugang, Anmeldung, Zahlungen, Erinnerungen. Er speichert keine Briefinhalte. |
| `ANLEITUNG.md` | Inbetriebnahme Schritt für Schritt. |

## Testseite

Bei jeder Änderung auf `main` baut GitHub die App und legt sie auf den Zweig `gh-pages`.
Adresse der Testseite: https://alexfelani.github.io/Briefe_App/

Die Testseite läuft ohne Server. Foto, Datei-Auswahl, Ablage, Export und Sperre funktionieren.
Lesen, Übersetzen und Antwortentwurf brauchen den Server mit KI-Zugang (siehe `ANLEITUNG.md`).

## Stand

Entwurf. Die Rechtstexte enthalten Platzhalter und sind nicht anwaltlich geprüft.
